# 🚀 Middle Frontend Developer Journey

Этот репозиторий документирует мой путь подготовки к позиции Middle Frontend Developer. Здесь собраны мини-проекты, демонстрационные приложения и финальный fullstack-проект, созданные для углубления фундаментальных знаний и отработки лучших практик.

## 📊 Прогресс обучения
- [ ] Организация рабочего пространства и планирование
- [ ] Фаза 1: Фундамент JavaScript & TypeScript (0/4 недель)
- [ ] Фаза 2: React & Next.js Deep Dive (0/4 недель)
- [ ] Фаза 3: Архитектура, тестирование и производительность (0/3 недель)
- [ ] Фаза 4: C# Backend (ASP.NET Core) Basics (0/3 недель)
- [ ] Фаза 5: Финальный Fullstack проект (0/6 недель)

## 🛠 Технологический стек
- **Frontend:** JavaScript (ES6+), TypeScript, React, Next.js, MobX, Zustand/Redux
- **Backend:** C# (ASP.NET Core Web API), Entity Framework Core
- **Инструменты:** Git, Webpack/Vite, Jest/Vitest, Playwright, Docker

## 📂 Структура репозитория
- `/01-js-fundamentals` – Мини-проекты для отработки основ JS/TS (Event Loop, замыкания, асинхронность).
- `/02-react-deep-dive` – Проекты по оптимизации рендеринга, кастомным хукам и управлению состоянием.
- `/03-architecture-testing` – Примеры реализации FSD/Clean Architecture и покрытия кода тестами.
- `/04-csharp-backend` – Учебные API и интеграция с фронтендом.
- `/05-final-project` – Полный цикл разработки fullstack-приложения.

## 📝 Правила работы
1. Каждая тема закрывается мини-проектом с тестами и README.
2. Код проходит самопроверку (linting, типизация) перед коммитом.
3. Используются атомарные коммиты с понятными сообщениями.
